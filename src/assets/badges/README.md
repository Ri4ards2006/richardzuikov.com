# Earned certificate badges

Drop the **official** badge of an earned credential here as `<id>.png`, where `<id>` is the certificate's `id` in `src/lib/translations.js` (`career.certificates`), e.g. `7Y5OLV313LZX.png` for AZ-900.

- Use the file the issuer gives you (Credly / Microsoft Learn / Coursera download). Never scrape, redraw, recolour or crop it: it is shown unmodified and in colour on the back of the KEY ITEMS card (DESIGN.md §2, §7).
- The badge links to `verifyUrl` only when that URL points at this exact credential; otherwise it is shown without a link.
- Until a file exists the card back keeps its line icon.
